# Коллектор OCPP и эмулятор станции (30.10.2026)

Реализация плана из [OCPP_ADAPTER_PLAN.ru.md](OCPP_ADAPTER_PLAN.ru.md). Проверена только на эмуляторе: реальной станции не подключали. Модуль необязательный: сервер ARGUS и образ Docker работают без пакета `ocpp`.

## Что есть

| Часть | Файл | Назначение |
|---|---|---|
| Отображение величин | `python/argus/ingest/ocpp_mapping.py` | `MeterValues` OCPP 1.6 → каналы ARGUS; единицы и фазы; ничего не додумывается |
| Хранилище | `python/argus/ingest/store.py` | SQLite, сырые значения, параметризованные запросы, дубликаты отбрасываются, дрейф часов и отброшенные времена пишутся в журнал; `idTag` не читается и не хранится |
| Сетка 5 с | `python/argus/ingest/resample.py` | Удержание последнего значения не дольше одного шага, без интерполяции; строка пригодна только если все шесть каналов свежие |
| Коллектор | `python/argus/ingest/csms.py` | Пассивный центр OCPP 1.6J: принимает телеметрию, **не управляет зарядкой** |
| Эмулятор | `python/argus/ingest/emulator.py` | Детерминированная станция: `healthy`, `overheating`, `missing_channels`, `duplicates`, `clock_drift`, `dropout` |
| Вход приёма | `python/argus/ingest/api.py` | `POST /api/ingest/equipment`, токен обязателен, лимит запросов |

## Запуск

```bash
python -m pip install -r python/requirements-ocpp.txt
export PYTHONPATH="$PWD/python:$PWD/build/cpp_core"
python -m argus.ingest.csms --port 9000
python -m argus.ingest.emulator --scenario overheating --count 120
```

Коллектор слушает `127.0.0.1`. На другом адресе он запустится только с учётными данными станций (переменная `ARGUS_OCPP_PASSWORDS`, формат `станция:пароль,станция2:пароль2`, HTTP Basic по профилю безопасности 1); TLS ставится перед ним обратным прокси. Токен приёма: `ARGUS_INGEST_TOKEN`; пока он не задан, вход отвечает 503.

## Ограничения

- Карты (`Authorize`, `StartTransaction`) коллектор **отклоняет**, поэтому реальная станция, подключённая к нему как к единственному центру, не начнёт сеанс. Он годится как сборщик телеметрии рядом с рабочим центром оператора, а не вместо него.
- OCPP не передаёт вибрацию. Без отдельного датчика строки сетки неполные и в модели не попадают; это покрыто тестами (`never_reported: vibration_g`).
- Полный разбор состояния требует волновой формы вибрации: без неё вход возвращает состояние буфера и причину `waveform_required_for_assessment`.
- Метки времени эмулятора виртуальные; признак `clock_drift` сравнивает их со временем приёма, поэтому в тестах с фиксированным началом он срабатывает по замыслу.
- Не проверено: интервал `MeterValueSampleInterval` и набор величин на реальных станциях, OCPP 2.0.1, нагрузка на коллектор.
- Модели оборудования обучены на синтетике; данные станций их не проверяют.
